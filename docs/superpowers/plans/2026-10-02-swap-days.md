# Swap Days Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each day column on the board gets left/right arrows that swap it with its neighbor for the viewed week; labels follow position and workouts travel with their data.

**Architecture:** A new `week.order` (a permutation of 1..7, absent when unchanged) says which program day sits at each workout position. A card's displayed column is derived in two steps: `order` gives its workout position, then the existing Rest-day shift (`shownDay`) gives the column. Swapping two visible workouts swaps two entries of `order`; swapping a workout with the rest column moves `week.rest`. Nothing stored is rewritten, and swaps are saved with the week like the rest day.

**Tech Stack:** React 19, zustand, vitest (Node, no DOM), SheetJS (`xlsx`), oxlint.

**Spec:** [docs/superpowers/specs/2026-10-02-swap-days-design.md](../specs/2026-10-02-swap-days-design.md)

## Global Constraints

- Branch `swap-days` (already created from `main`); one commit per task; commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- `DAY_COUNT = 7`. `week.order` is an array of exactly 7 distinct integers 1..7; absent when it equals the identity `[1,2,3,4,5,6,7]`; never written as `null`; anything that is not a clean permutation is ignored on load.
- Labels follow position ("Day N" = the Nth column). A workout's subtitle, make-up flag, warm-up ticks, check-offs, logs, phases, skips and moved cards travel with it (they are keyed by program day / slot id).
- With a rest day set, the board shows 6 workout columns plus the rest column; the 7th workout position stays off the board and empty (the existing "no room" block guarantees it). Arrows never touch it.
- Swapping a workout with the rest column moves the rest day (it takes the workout column's position). The first column has no left arrow and the last no right arrow (hidden, not disabled).
- Status message after a swap: `Day {d} swapped with Day {e}` (or `Rest day moved to Day {n}` when the rest column is involved). Focus then moves to the same-direction arrow of the column the workout moved to (the other arrow if that column is at the end).
- The "From Day N" badge shows only for cards the user moved (`week.moved[id]` is set); N is the displayed column of the card's home workout.
- WCAG 2.2 AAA: arrow buttons are real buttons, 44 px minimum target, descriptive names ("Swap Day 6 with Day 7") with `aria-hidden` glyphs, no drag required.
- Excel `Check-offs` sheet: an `order` row kind whose value is space-separated (`3 1 2 4 5 6 7`); the reader accepts spaces or commas.
- Code style: match the surrounding code (dense one-liners, comments only for non-obvious rules). Tests: `npx vitest run <file>`; all `npm test`; lint `npm run lint`; build `npm run build`.

## Review Focus

1. A swap that would touch the hidden 7th workout position while a rest day is set: arrows on every visible column must keep `order[6] === 7`. Test in Task 3.
2. An invalid or stale `order` (duplicates, wrong length, strings, out of range) from JSON, Excel, or a merged device must be ignored, not crash or hide cards. Tests in Tasks 1 and 2.
3. Moving a card by drop or menu after a swap must land on the workout shown in that column, and undo must restore it. Test in Task 3.
4. A swap must not make every swapped card look "moved" (badge only for `week.moved`) and must not lose warm-up ticks. Warm-up test in Task 3; badge checked by hand in Task 4.
5. Resting after swapping the empty day away from the end must be blocked with the existing message; swapping it back to the end must re-allow it. Tests in Tasks 1 and 3.

// week.order[i] = the program day shown at workout position i + 1 (absent = normal order).
export const isOrder = o => Array.isArray(o) && o.length === DAY_COUNT && o.every(v => Number.isInteger(v) && v >= 1 && v <= DAY_COUNT) && new Set(o).size === DAY_COUNT;
export const orderOf = w => (w && isOrder(w.order) ? w.order : DAYS);

  swapDays(d, dir) {
    const e = d + dir; if (e < 1 || e > DAYS.length) return false;
    const w = get().week; const restInvolved = w.rest === d || w.rest === e;
    const ok = get().mutateWeek(x => {

// Left/right arrows that swap a column with its neighbor. Focus follows the workout to its new column.
function SwapArrows({ d }) {
  const swap = dir => {
    useAppStore.getState().swapDays(d, dir);
    const e = d + dir;
    requestAnimationFrame(() => (document.getElementById(`swap-${e}-${dir}`) || document.getElementById(`swap-${e}-${-dir}`))?.focus());
  };
  return (
    <span className="swaps">
      {d > 1 && <button type="button" className="btn sm ghost swapbtn" id={`swap-${d}--1`} aria-label={`Swap Day ${d} with Day ${d - 1}`} onClick={() => swap(-1)}><span aria-hidden="true">←</span></button>}
      {d < DAYS.length && <button type="button" className="btn sm ghost swapbtn" id={`swap-${d}-1`} aria-label={`Swap Day ${d} with Day ${d + 1}`} onClick={() => swap(1)}><span aria-hidden="true">→</span></button>}
    </span>
  );
}
